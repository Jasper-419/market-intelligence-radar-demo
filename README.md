# 腾讯广告行业机会 Demo

个人面试作品，非腾讯官方产品。使用国内公开资料快照，不使用内部客户、账户投放消耗或预算数据。

线上演示：https://jasper-419.github.io/market-intelligence-radar-demo/#opportunities

## 演示链路

- 项目理解：竞媒投放规则与扶持、行业统计/报告与企业财报两条外部主线。
- 行业机会：行业变化、竞媒政策、企业案例三个子视图；事实 → 行业影响 → 企业 → 腾讯相关假设 → 跟进动作。
- 资料与证据：统一检索政策、行业统计、研究报告和企业披露，查看期限、正文覆盖、官方原文与指纹，导出研究清单和企业简报。

核对截至 2026-10-25；14条研究线索（含下线归档）、17份主要来源、2条扶持线索。完整核验的现行扶持0条；受限附件、未披露截止及后台条件明确待补，不当作已确认商机。三家企业案例另保留16处摘录与相关历史能力背景来源。

旧 #case 链接继续打开企业案例；#policies 打开竞媒政策；#updates 打开统一资料检索。

## 本地运行

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765/#opportunities 。不要直接双击HTML，因为页面需要读取两个公开JSON。

## 资料与许可

data/business-signals.json 为行业与政策短整理；data/case.json 为企业案例与引用。正文通过官方链接查阅，不再分发完整第三方PDF或受限附件。经营费用、零售数据与广告消耗口径不同，建议属于待业务确认的研究假设。

代码许可见LICENSE；字体、GSAP资产声明在static/vendor/。本仓库仅部署静态演示，不含密钥、数据库、原始浏览记录，不运行自动采集、定时或联网模型。
