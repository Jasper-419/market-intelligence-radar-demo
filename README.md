# 腾讯广告行业机会 Demo

个人面试作品，基于外部公开经营变化形成行业与企业跟进假设。非腾讯官方产品；不使用内部客户、广告消耗或预算数据。

这是可直接托管的静态展示版本，不需要后端、API Key 或定时任务。

## 在线演示

https://Jasper-419.github.io/market-intelligence-radar-demo/#case

## 演示内容

- 项目理解：解释内部 / 外部视角分工与来源到跟进动作的链路。
- 行业机会：贝泰妮、珀莱雅、丸美生物的经营变化、对比图表、证据链、腾讯相关假设及跟进条件。
- 资料与证据：检索案例摘录，查看官方来源、披露日期、统计期、页码与 SHA-256，导出证据 JSON 和简报。

核对截至 2026-10-25；6 份公开披露、16 条关键摘录。财报仍按真实统计期展示。公开销售费用不等同广告费，研究建议不是已确认预算。

## 本地打开

在本目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765/#case 。不直接双击 index.html，因为页面需读取 data/case.json。

## 数据与许可

事实快照位于 data/case.json，保留原始公开来源。全文仅链接到来源站，不再分发第三方 PDF；页面中的短摘录不表示完整报告正文已验收。腾讯能力材料为历史背景，未标注准确发布日期时不当作新政策。

代码许可见 LICENSE。字体与 GSAP 的第三方声明位于 static/vendor/，对应资产遵循各自许可。

这个仓库只包含面试展示快照，不部署自动采集服务或联网模型。不含密钥、数据库或本地运行日志。
